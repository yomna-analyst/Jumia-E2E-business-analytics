# 🚀 Jumia E2E Business Analytics Dashboard

End-to-end analytics project analyzing Jumia’s e-commerce ecosystem (Marketplace, Logistics, Marketing, and Customers) using Power BI.

---

## 🎯 Objective
Improve profitability and operational efficiency while maintaining a strong customer experience.

---

## 📊 Key Dashboards

- **Executive Dashboard:** Net Sales, Profit, Orders, Return Rate  
- **Sales Analytics:** Revenue, Profit, Margin, Top Cities  
- **Logistics Analytics:** Delivery Performance & Return Rate  
- **Marketing Analytics:** Spend vs Orders, Cost per Order  
- **Customer Analytics:** Segmentation & Customer Value  

---

## 🛠 Tools
Power BI | Power Query | DAX

---

## 💡 Impact
- Better profitability insights  
- Optimized marketing spend  
- Improved logistics performance  
- Data-driven decision making
